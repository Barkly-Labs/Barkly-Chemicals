# ChemCraft texture mapping and visual references

All 30 registered item textures are distinct 16×16 transparent PNGs. Each item model under `assets/barklychemlab/models/item/` points to the matching `assets/barklychemlab/textures/item/<registry_id>.png`. The art was generated as individual item icons, then reduced with nearest-neighbor sampling to preserve hard pixel edges.

## Verification

- Every registered item ID has one model, one translation, and one matching texture file.
- Every item texture is a unique 16×16 RGBA PNG; no duplicate file hashes were found.
- Minecraft resource JSON resolves each item model to the matching texture path.
- The compiled JAR contains the complete texture set and model resources.
- Visuals were checked as a contact sheet at Minecraft item scale. A live Minecraft client was not launched in this environment, so GUI/inventory runtime appearance remains subject to in-game playtesting.
